# 成长足迹审核清单

用于检视 `D:\travelRecord\life-journal` 的成长足迹相关内容。
**审核者不应修改任何文件**，只报告问题。

## P0 =阻塞，必须修

| # | 检查项 | 方法 |
|---|---|---|
| P0-1 | **构建必须成功** | 跑 `node scripts/build.js`，非0 退出或有异常即 P0 |
| P0-2 | **图片引用必须全部存在** | md 里每个 `photos:xxx` 与 `photos/<slug>/xxx` 实际文件比对，缺失即 P0（会渲染成碎图） |
| P0-3 | **不能有未替换的模板变量** | 产物 HTML 里搜 `{{`，有即 P0 |
| P0-4 | **不能残留已废弃的类名/语法** | 成长区不应再出现 `tl-item`/`tl-card`/`timeline`/`milestone`（已改月刊结构） |
| P0-5 | **slug 与文件名/目录必须一致** | `slug: 2026-09` ⇒ 文件 `2026-09.md` + 目录 `photos/2026-09/` |

## P1 = 重要，影响质量

| # | 检查项 | 方法 |
|---|---|---|
| P1-1 | **文案八条禁令** | 逐条对照（见下），违反即 P1 |
| P1-2 | **front-matter 必填字段齐全** | `title`/`date`/`slug`/`birthdate` 缺一即 P1 |
| P1-3 | **年龄必须正确** | 核对 `birthdate` + `date` 与页面显示的年龄是否吻合；`age` 字段与自动计算值冲突即 P1 |
| P1-4 | **年月显示一致** | 页眉 `al-yy`/`al-mm`、页脚、封面卡片的年月必须与 `month` 字段一致 |
| P1-5 | **数据卡语法完整** | `::: stats` 必须有对应 `:::` 闭合，产物里不能残留 `:::` |
| P1-6 | **引用块不被拆散** | 序/小结的连续 `> ` 行应合并为单个 `<blockquote>`，拆散即 P1 |
| P1-7 | **图片不得重复出现在同一篇** | 同一 slug 下文件名不得在正文重复引用 |
| P1-8 | **生长足迹数量一致** | 首页相册卡片数 == `content/growth/*.md`（除 `_template`）数量 |

## P2 = 建议

- 正文 300–550 字。**低于 300 字不必报问题** —— 素材里的客观事实写完就是写完了，不靠形容词凑字数；但明显不足 200 字时提示「可能漏写了客观事实（时间/地点/气温/服饰/动作）」
- 图说 4–8 字，只标主体，不加形容词
- 未引用的照片应进底部「其余照片」相册
- 移动端断点是否覆盖新类名
- `PROJECT_SUMMARY.md` 是否已同步（改代码/结构/规范后）
- 变更日志是否追加

## 文案八条禁令（P1-1 细则）

| 禁令 | 反例特征 |
|---|---|
| 1 不煽情 | 「这些小事就没有人记得了」「希望她一直这样」 |
| 2 不编对话 | 引号内的话必须是家长确认过的原话 |
| 3 不转述对话 | 「她问是不是…」「她说…」 |
| 4 不写心理活动 | 「她关心的重点是…」「她最喜欢…」「她好奇…」 |
| 5 不叙述过程 | 「开车从山脚一路盘上去…」 |
| 6 不对比修辞 | 「不是A，是B」 |
| 7 不总结断言 | 「总…」「所以…」「居然…」；**涉及"经常性"必须问家长** |
| 8 不延伸结尾 | 「下个月继续」「天气开始凉了」 |

**允许**：客观事实（时间/地点/海拔/气温/服饰/动作）、可验证的观察、4–8 字图说。
**结尾**用客观小结，如「两趟出行，十一张照片。九月结束。」

## 报告格式

```
## 审核结果：<主题>
构建：✅/❌
P0：N 项 / P1：N 项 / P2：N 项

### [P0-1] 标题
位置：文件:行号
现状：
问题：
建议：
```

只报不改。P0/P1 未清零不得交付。
